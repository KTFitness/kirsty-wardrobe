# Kirsty's Wardrobe

A phone web app for browsing Kirsty's clothes and outfit ideas. Hosted on GitHub Pages.

- `data/wardrobe.json` holds items, outfits and inspiration looks.
- `img/` holds the cut-out photos.
- Favourites, hidden outfits and outfits built in the app are saved on the phone only.

New items and outfit ideas are added by Claude in chat.
